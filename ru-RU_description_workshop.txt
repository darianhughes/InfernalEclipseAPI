[h1]Infernal Eclipse of Ragnarok[/h1]
[h3]Ультрамодифицированный аддон для Infernum[/h3]

[b]Первым делом советуем вам оценить соответствующий модпак по этой ссылке:[/b]
https://steamcommunity.com/sharedfiles/filedetails/?id=3456508757

Infernal Eclipse of Ragnarok - ультрамодифицированный аддон для Infernum Mode, добавляющий поддержку крупных контентных модов, находящихся в самой сборке:
[list]
	[*] Calamity Mod и пара его аддонов
	[*] Thorium Mod
	[*] Secrets of the Shadows
	[*] Consolaria
[/list]

На данный момент API добавляет:
[list]
	[*] Более 1000 переключаемых изменений баланса для предметов, добавляемых модами этой сборки, которые значительно улучшают получаемый игроком опыт при прохождении мода.
	[*] Совмещение древ крафтов у кучи аксессуаров.
	[*]	Вступительные анимации Infernum для боссов из других модов у которых их до этого не было.
	[*] Изменения характеристик боссов для режима Инфернум, чтобы сложность боссов из мода в мод оставалась на примерно одном уровне.
	[*] Новая сложность: Рагнарёк.
	[*] Немного изменённый Босс-раш с поддержкой каждого босса из модпака вместе с кастомным «6 рангом».
	[*] Новые саундтреки для некоторых моментов игры.
	[*] Изменения в генерации мира, позволяющие биомам/структурам разных модов спокойно сосуществовать друг с другом в одном мире.
	[*] Исправления ошибок, улучшающие совместимость Infernum с мультиплеером.
	[*] Множество небольших улучшений совместимости для разных модов вне основной сборки.
[/list]

В моде также есть некоторые уникальные встроенные системы, такие как:
[list]
	[*] Система, предоставляемая [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3535746309]Thrower Unification[/url], объединяющая разбойника с метателем в один класс и дополнительно добавляющая уникальные скрытные удары для некоторых метательных предметов из Thorium.
	[*] Настраиваемая система возрождений в мультиплеере, позволяющая выставить максимальное количество возрождений для каждого игрока во время битвы с боссом (по умолчанию значение выставлено на 1 в режиме Инфернум и выше).
	[*] Система, позволяющая отключить возможность менять сложность игры через интерфейс Calamity.
	[*] Система, позволяющая призывать Астрагельдона даже после победы над Лунным лордом.
[/list]

В будущем у этого мода планируется своя история, включающая в себя и другие моды сборки, а также переработку боссовой прогрессии с использованием модов [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3747472937]Quest Books[/url] и [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3446119263]tPackBuilder[/url].

Сборка была разработана с учётом совместимости с мультиплеером, но это не гарантирует того, что вы не встретите никаких ошибок при игре в нём, ведь модпак всё ещё доделывается и тестируется.

Если вы нашли какие-либо ошибки при игре с модом, пожалуйста, напишите нам о них на нашем [url=https://discord.gg/tc5nZdRvaU]Discord-сервере[/url]. 

Также у мода есть своя [url=https://terrariamods.wiki.gg/wiki/Infernal_Eclipse_of_Ragnarok]страница на вики[/url]; посетите её, если у вас есть какие-либо вопросы по поводу сборки.

Если вы хотите поддержать команду копеечкой, то у вас есть возможность сделать это на странице IEoR в Patreon: https://www.patreon.com/c/InfernalEclipseofRagnarokTeam.
